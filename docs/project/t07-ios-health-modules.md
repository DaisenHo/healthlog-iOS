# T07：iOS 健康记录、图表与档案中文闭环

对应 [iOS #2](https://github.com/DaisenHo/healthlog-iOS/issues/2)，基于 T02 的账户语言。本任务不代表 M1 已经发布。

## 范围

用户用简体中文浏览和操作现有健康测量、图表、档案，以及其他健康模块。精确范围由 `scripts/t07_zh.py` 从这些目录的可见文案和运行时拼接的词条前缀算出，并记在 [词条覆盖](t07-localization-coverage.json)。

范围内的词条都有简体中文。德文和英文原文保留。已授权问卷的题目、回顾期题干、选项和 PHQ-9 后续题保持原文，不进入中文目录；中文界面会显示“题目使用英文原文”的说明。药物浓度曲线的来源说明也保持原来的德英，避免和图表上未翻译的标题不一致。

覆盖的界面包括：测量与录入、图表、首页、健康分析、自定义指标、生理周期、检验、心情、疾病记录、文档、心理健康外壳、营养、环境、个人资料、档案、成就、锻炼，以及这些界面共用的设计系统、来源说明和错误文案。一个词条被多处使用时，覆盖清单只把它记在其中一个模块下。

沿用既有 String Catalog。药名、用户填写的疾病和指标名称、自由文本不自动翻译。数值、单位、来源、时区和原始记录保持原有读写行为。

## 日期

账户语言为简体中文且日期格式为自动时，数字日期按年、月、日显示，月份和星期使用中文。明确选择日/月/年、月/日/年或年/月/日时，数字顺序不变；带月份或星期的样式，以及 12 小时制的上午、下午和晚上，仍使用中文。计量单位和账户时区不变。

## 留给后续任务

用药、GLP-1、通知、提醒与目标设置、医生报告、权限说明、Widget、Watch、通知扩展、设置其余页面、引导和助手对话仍按原语言显示，缺少中文时回退英文。这些模块分别由 T08、T09 和最终验收处理。药物浓度图的既有德英说明保持只有这两种语言。

## 验证

- `scripts/t07_zh.py --check` 核对范围内词条都有非空中文、德英仍在、问卷原文没有中文，以及带参数的词条格式签名一致。
- `AccountLanguageTests` 核对体温、体重、血压的中文，以及 PHQ-9 题目仍为英文原文。
- `HLDateFormatTests` 核对中文自动日期的年月日顺序，以及日/月/年下的中文月份和 12 小时制。
- 既有目录、标点和德文泄漏检查通过。模拟器上的小屏、动态字体和完整界面旅程不在本次自动化结果里；不能据此声称已经完成真机或全套界面验收。
